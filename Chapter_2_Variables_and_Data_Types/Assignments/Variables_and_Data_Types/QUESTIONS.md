# Variables & Data Types — Assignment Questions

## Question 1: Average of three numbers
Input three numbers `A`, `B`, and `C`. Print their average.

## Question 2: Area of a square
Input the side of a square and print its area. Hint: `area = side * side`.

## Question 3: Bill for three items
Input the costs of a pencil, pen, and eraser using `float`. Print the total bill.
Advanced: Add 18% GST and print the final bill.

## Question 4: Type of the expression
What is the data type of the result?

```java
byte b = 4;
char c = 'a';
short s = 512;
int i = 1000;
float f = 3.14f;
double d = 99.9954;

var result = (f * b) + (i % c) - (d * s);
```

Hint: Consider Java numeric promotion rules.
