# Chapter 1 Assignment Answers

## Cropped course flowcharts
The `Cropped Flowchart Answers` folder contains tightly cropped images of the four flowchart solutions supplied in the screenshots:
1. Area of a circle
2. Greatest of two numbers
3. Even numbers
4. Average of 25 exam scores

## Text answers
- `Assignment Questions.txt` contains the four questions.
- `Solution Sheet.txt` contains algorithms, pseudocode, Java solutions, and flowchart steps.

## Important note about Question 3
The supplied course flowchart checks `I <= 98` after printing and incrementing, so it prints even numbers from 10 through 98. If your instructor interprets “between 9 and 100” as inclusive, include 100 by using a loop that prints while `I <= 100`.
